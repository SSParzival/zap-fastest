Fork starting point: `792881fc`; common ancestor: `df01459f`.
The comparison contains 111 upstream-only commits and 64 associated merged PRs.
Patch IDs alone undercount integrations because this fork adapted features to
account ownership, archive encryption, durable sends and privacy. The maintained
[backlog](development-backlog-20261010.md) supplies the older integration receipts;
this review refreshes source differences and the newly merged PR context.

New application integrations are the remaining #468 picker behavior and #479
launch invites. #468 credit: claudiocp and Carmine Paolino. #479 credit: Tássio
Guerreiro Antunes Virgínio and Carmine Paolino. Picker retries retain this fork's
explicit-download/export policies, background batching and cancellation.
A click paused by 429 also survives until the pause ends. Invite access codes
remain out of Debug output and off the unauthenticated legacy port.

#435 is already covered by our label-sized, viewport-bounded scrolling submenus.

samples are ignored; actual device failures are surfaced and Stop remains
interruptible. Do not replace this with upstream's uninterruptible iterator.
The upstream catalog update has no untranslated shared msgids to fill. New
minimize/restore labels were added in all ten existing locales separately.

ZapFastest 0.36.0 integrates fixes and protocol updates from upstream ZapFast 0.21.3 together with memory, media, and interface improvements adapted from the Zeus fork. Existing linked accounts preserve their sessions, encrypted SQLCipher archives, and settings.

## Performance and memory

- **Batched archive writes during sync.** History chunks and queued runtime events now commit in savepoint-backed batches (`archive::Batch` / `Archive::begin_batch`) instead of one transaction per message, cutting disk write amplification during initial sync and parallelizing shutdown across accounts.
- **Tighter GPU and texture budgets.** Lowered image cache residency to 96 entries and 48 MiB, stepped avatar and still-sticker decode sizes, capped viewer textures to window/zoom pixel steps (`4096` px max), virtualized sticker picker rows, released sticker textures when closing or switching tabs (`picker::release_stickers`), and cleared idle glyph atlases after 60 seconds.
- **Deferred archived chat sync.** Sync work for archived chats waits while active conversations load, avoiding wasted startup CPU and disk I/O.
- **Bounded HTTP requests.** Added connect, read, and total request timeouts (`HTTP_CONNECT`, `HTTP_ANSWER`, `SMALL_REQUEST`) so stalled media or metadata fetches cannot hold worker tasks indefinitely.

## New and improved

- **Per-chat wallpapers.** Set, change, or remove a custom wallpaper image for any conversation from the chat header menu, stored per account and kept separate from the global account wallpaper.
- **Voice message scrubbing and controls.** Drag directly across the waveform bar to scrub with live duration feedback, bare play/pause glyph on voice notes, refined waveform bar spacing and seek knob, and a solid contrast-aware playback speed chip.
- **Chat list preview glyphs and row dividers.** Expanded typed media preview icons for GIFs, locations, contacts, polls, view-once items, and voice/video calls (with danger-tinted missed call glyphs), plus subtle hairlines under resting chat rows.
- **Quote thumbnails and view-once replies.** Inline quotes and the composer reply strip now display cropped square thumbnails for photos and videos, and view-once media can be replied to safely without quoting keys or thumbnails.
- **Faster image handling.** Clicking an image or sticker while it is still decoding opens it directly in the viewer, wide staged pictures preserve their aspect ratio inside composer tiles, and album items follow automatic download rules individually.
- **Bundled Emoji 18.0 font and filtering.** Updated the bundled Noto Color Emoji CBDT font and filtered pickers and `:` completions through `emoji::catalogue` / `emoji::lookup` against `BUNDLED_VERSION` so offered emoji always render.
- **HD media retries and video thumbnails.** Improved HD photo copy handling (`hd_copies`), retry behavior, and local video thumbnail extraction.

## Fixed

- **Protocol decryption and device identity checks.** Updated `whatsapp-rust` to rev `719f2949`, resolving messages stuck on "Waiting for this message", fixing canonical registered phone lookups (including 9-digit Brazilian mobile numbers), preserving forwarded mention names without re-notifying, and keeping group mention resolution intact.
- **Wayland clipboard persistence and window fixes.** Added Wayland clipboard handoff (`wl-clipboard-rs`) so copied text remains pasteable after closing to the tray, updated `crmne/egui` (`06da5ee2`) and `crmne/winit` (`dc09323e`) for Windows NVIDIA flicker and macOS accent-picker double-character fixes, and enabled `NSSupportsAutomaticGraphicsSwitching` in `Info.plist` for dual-GPU Intel Macs.
- **Call stability.** Added a 120-second ring timeout (`RING_LIMIT`) so stale unended rings cannot block later calls, and guarded Accept buttons while connecting so double-clicking Accept no longer drops incoming calls.
- **M4A playback.** Switched audio decoding to `rodio::Decoder::try_from(file)` so M4A files whose index atom (`moov`) sits after audio data play cleanly.
- **Linux packaging compatibility.** Switched RPM dependencies in `native-packages.yaml` to 64-bit shared library sonames, added `libasound2t64 | libasound2` for Debian/Ubuntu, and added openSUSE Leap 16.0 (`zypper`) install verification in `packaging/test-install.sh` and `.github/workflows/packaging.yml`.

## Verification and limitations

Linux verification passed locally before tagging:
- Default features (`cargo test --locked --all-targets`): 2,224 passed (2,208 lib, 13 bin, 3 integration), 0 failed, 16 ignored.
- All features (`cargo test --locked --all-targets --all-features`): 2,226 passed (2,208 lib, 15 bin, 3 integration), 0 failed, 16 ignored.
- Release binary compilation (`cargo build --locked --release`), formatting (`cargo fmt --all --check`), Clippy (`-D warnings` on default and `--all-features`), rustdoc (`-D warnings`), dependency-source checks, shell syntax checks, and Flatpak packaging tests all exited 0.

Tests run on Linux only. Windows and macOS binaries and installers are compiled and packaged on GitHub Actions without application test execution. Windows installers are not Authenticode signed, macOS builds are ad-hoc signed without Apple notarization, and releases built without `ZAPFAST_GIPHY_KEY` omit an embedded Giphy key.

## New in 0.37.1

- **CachyOS and Arch Linux x86_64 release pipeline.** Streamlined GitHub Actions (`ci.yml`, `packaging.yml`, and `release.yml`) to build and verify only Linux x86_64 targets relevant to CachyOS: the portable `x86_64-unknown-linux-gnu` tarball (for direct installs and signed in-app self-updates) and a native `zap-fastest-bin-0.37.1-1-x86_64.pkg.tar.zst` package ready for `pacman -U`. Removed unused Windows, macOS, ARM64, Nix, Flatpak, DEB, and RPM jobs.
- **Image preview margin click fix.** Registered margin hit targets inside the active scroll-area layout pass so clicking outside a fitted image reliably closes the viewer while keeping picture interactions intact.
- **Arch PKGBUILD and Cargo manifest cleanup.** Added `libwebp` to source Arch PKGBUILD dependencies (`zap-fastest` and `zap-fastest-git`), scoped `zap-fastest-bin` cleanly to `x86_64`, and removed the redundant `package.homepage` field from `Cargo.toml`.

## Highlights included from 0.36.0 and 0.37.0

- **Performance and memory.** Purged idle thread-local mimalloc heaps (`libmimalloc-sys`), windowed text-selection layout to visible and anchor rows, cached and virtualized search results, tuned Linux/Windows image cache budgets (`256` entries / `128 MiB`), batched archive sync writes, and made inline markup parsing linear-time with URL protection.
- **Audio stickers and media.** Added full audio sticker playback, download, reupload recovery, and animation sync inline and in the sticker modal; paused inline video when handing off to external players; added YouTube oEmbed and Instagram link previews; and bounded audio decode duration and sticker ZIP extraction.
- **Security and privacy.** Updated `url` (`2.5.9`), `form_urlencoded` (`1.2.3`, `RUSTSEC-2026-0592`), and `rustix` (`1.1.6`); hardened channel picture SSRF validation; redacted JIDs from worker logs; purged raw protobuf blobs and cached files on message revocation; and persisted suspend-aware lock backoff with a 6-character chat-lock minimum.
- **Protocol, Wayland, and UI.** Added extended V5/V6 polls with `hide_voter_names`, tracked `edit_ids` for receipts, added QR expiration recovery and phone-pairing socket readiness, fixed Omarchy `Super+V` clipboard paste and minimized focus handling, added Wayland clipboard persistence (`wl-clipboard-rs`), and refined composer sizing and narrow-window layouts.

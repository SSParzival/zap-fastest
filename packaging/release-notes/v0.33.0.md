## New

- **Contact blocking and blocklist management.** Manage blocked contacts directly from settings with per-account isolation. Synchronizes block/unblock state securely with WhatsApp's privacy API.
- **Chat export with media.** Export entire chats to standard WhatsApp formatted text (`_chat.txt`) with accompanying photos, videos, audio, and documents.
- **Broadcast list handling.** Fully supports incoming and outgoing broadcast lists in the local encrypted SQLite archive, preserving recipient rosters and delivery status.
- **Outgoing link previews.** Automatically generates link previews for URLs entered in the composer, respecting the account's server privacy configuration.
- **Persistent voice note playback bar.** Switching chats no longer interrupts voice note playback. A compact floating bar retains play/pause controls, progress scrubbing, and quick navigation back to the originating chat.
- **Full-size staged attachment review.** Review, crop, and inspect staged photos and media in full size prior to sending.
- **WhatsApp Lottie stickers.** Supports animated `.was` stickers rendered in-process with rasterlottie.
- **Group description editing & disappearing messages.** Group admins can edit group descriptions, and conversation settings allow toggling ephemeral timers (24 hours, 7 days, 90 days, or off).

## Improvements & Fixes

- **Audio device idling.** Pausing voice notes or media releases the sound output stream immediately so system audio hardware can sleep, while preserving precise playback position.
- **Dynamic tray badge.** The system tray icon displays badges for unread chat counts up to 9+, with left-click toggle support on Windows.
- **Album reply quote deduplication.** Replies to media albums now consolidate redundant quotes into a clean summary.
- **Responsive header.** Vibrant chat headers automatically fold action buttons into a menu when window width is constrained, preventing overlap with the chat title.
- **Clipboard paste polish.** Ctrl/Cmd+Shift+V pastes unformatted plain text into the composer without triggering image or file attachment staging.
- **Word-start contact search.** Contact searching matches words in start-order across contact names and phone numbers.
- **Multi-account notifications.** Notifications clearly display the destination account name when multiple WhatsApp accounts are active.
- **View-once media replies.** Replying to view-once media generates appropriate context quotes without exposing burned media contents.
- **Emoji and sticker pickers.** Emoji picker automatically closes on send, and sticker picker preserves tab and position state.

## New

- **Faster message search with an encrypted FTS5 trigram index.** Searches of three or more characters query SQLite FTS5 (`message_text`) kept in sync by triggers, while existing archives backfill incrementally in worker batches without stalling startup.
- **Bounded memory for images, conversations, and media decoders.** Chat images decode off the interface thread at display size and follow a 256-entry, 128 MiB cache with 30-second idle and minimized-window eviction. Each account keeps only the open chat and its two most recent chats in memory, dropping older pages back to SQLite.
- **Lower RSS peaks and streaming sync.** Consolidates `mimalloc` (`0.1.52`) to return freed sync and media peaks to the OS, streams history sync and sticker pack imports, shares contact records via `Arc`, and avoids unnecessary clones in chat/search lists.
- **Groups in common and faster New chat selection.** Contact info shows shared groups (`Groups in common`) with direct jump links, and pressing Enter in a non-empty New chat search immediately opens the first matching chat.
- **Hardened v0.21 feature set now published in a tagged release.** Includes contact blocking, chunked chat exports with media, received broadcast list sync, privacy-gated outgoing link previews, persistent voice playback across chats, full-size attachment staging, and bounded Lottie (`.was`) sticker rendering.
- **Unified `zap-fastest` release naming.** Binary archives, Linux packages, Windows installers, macOS DMG, and Flatpak bundles for v0.35.0 onward all ship under `zap-fastest` while preserving keyring, profile, and updater compatibility contracts.

## Fixed

- **Dependency advisories and MP4 parser hangs.** Updates `quinn-proto` to `0.11.19` and `quinn-udp` to `0.5.16` to resolve `RUSTSEC-2026-0523`, `RUSTSEC-2026-0524`, and `RUSTSEC-2026-0538`. Validates MP4 box trees in `mp4_guard` before parsing headers so malformed empty or cyclic boxes cannot hang playback.
- **Link watch, panic containment, and decoder release.** Reconnects promptly on `link_watch` socket loss, isolates decoder worker panics, updates `whatsapp-rust` (rev `e634d245`) and `rusqlite` (`0.43` with bundled SQLCipher), and rebuilds font atlases cleanly by generation.
- **Privacy and security hardening.** Proxy configurations fail closed on link-preview DNS guards, disable/logout/app-lock actions cancel in-flight previews, Lottie preflight rejects cyclic assets and raster/expression/repeater payloads, hidden-account exports keep their own progress and toast state, and ZIP export names cap UTF-8 byte lengths.

## Verification and limitations

Linux checks passed with 2,174 default-feature tests (2,159 lib, 13 bin, 2 integration) and 2,176 all-feature tests (2,159 lib, 15 bin, 2 integration), each with zero failures and 15 existing hardware/manual tests ignored. Formatting, both Clippy configurations (`-D warnings`), rustdoc (`-D warnings`), dependency-source checks, packaging scripts, release compilation, and local user installation all passed.

Tests run on Linux only. Windows and macOS binaries and installers are compiled and packaged on GitHub Actions without application test execution. Windows installers are not Authenticode signed, macOS builds are ad-hoc signed without Apple notarization, and releases built without `ZAPFAST_GIPHY_KEY` omit an embedded Giphy key. Live WhatsApp linking, sync, and device audio/video require attended runtime confirmation.

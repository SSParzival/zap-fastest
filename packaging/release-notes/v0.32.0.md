ZapFastest 0.32.0 brings keyboard navigation through messages, a notification bell for each account, and download folders that stay with their chats. It also recovers older encrypted edits and stars, marks unheard voice notes, and repairs missing or damaged stickers without a download loop.

## New

- **Navigate messages with the keyboard and screen readers.** The message list exposes spoken labels and supports arrows, Home, End and page keys. Remembered positions belong to their account and chat. Adapted by @SSParzival from ABDULAZIZ ALSHMASI's [upstream #504](https://github.com/crmne/zapfast/pull/504).
- **Mute an account from its notification bell.** The switcher keeps muted unread counts visible in grey while excluding them from process badges. Adapted by @SSParzival from Rodolfo Michetti's [upstream #628](https://github.com/crmne/zapfast/pull/628).
- **Keep downloads organized by account and chat.** New configurations use account/chat folders; existing organization choices stay. Folder assignments survive restarts, chat renames and privacy-ID merges. Adapted by @SSParzival from @eternalwaitt's [upstream #616](https://github.com/crmne/zapfast/pull/616).
- **See which voice notes remain unheard.** An accent dot disappears after playback here or on the phone, and consecutive playback skips notes already heard there. Adapted by @SSParzival from Bruno Costanzo and Carmine Paolino's [upstream #538](https://github.com/crmne/zapfast/pull/538).

## Fixed

- **Older encrypted edits and stars recover when linking.** History preserves edit targets, message order, downloaded media and newer local changes. Adapted by @SSParzival from @crmne's [upstream #582](https://github.com/crmne/zapfast/pull/582) and [#604](https://github.com/crmne/zapfast/pull/604).
- **Missing or damaged stickers can recover.** Decode failures clear stale caches and allow one automatic recovery attempt, then offer manual retry. Adapted and extended by @SSParzival from @crmne's [upstream #603](https://github.com/crmne/zapfast/pull/603).
- **Voice receipts respect privacy.** Private played receipts wait for known server privacy settings, and the account's read-receipt preference still gates network sends. Heard state remains local when receipts are off. Adapted by @SSParzival from @crmne's [upstream change](https://github.com/crmne/zapfast/commit/5e8ae88).
- **Text editing and phone links keep their keyboard behavior.** Nonempty text fields retain Ctrl+End, and wrapped phone links follow the message list in Tab order. French numbers now use their own grouping, adapted from Alexandre Augrain's [upstream #632](https://github.com/crmne/zapfast/pull/632).
- **Media and selection remain usable.** This release includes the pending Linux PRIMARY-selection and middle-paste fixes, video B-frame timing and WebP decoding fixes, picker dismissal and contact-name refreshes. Non-MP4 video containers use the document path rather than an unsupported inline player.
- **Release packaging consumes the executable Cargo builds.** Linux packages use the Debian 12 ABI baseline, Flatpak selects one desktop entry, and macOS bundle paths match their declared executable and icon. Installer checks recognize ZapFastest's current filenames.

## Verification and limitations

Linux verification passed with 2,015 tests in the default suite and 2,017 with all features, with no failures and 14 existing ignored tests in each. Formatting, both Clippy configurations, rustdoc, package checks and six native demo captures passed. The [verification receipt](https://github.com/SSParzival/zap-fastest/blob/v0.32.0/docs/verification/release-0.32.0.json) records the commands and results.

Tests run on Linux only. Windows and macOS release artifacts are built and packaged without application test execution. Synthetic tests and demo windows do not establish live WhatsApp delivery, phone synchronization, physical audio/video, or screen-reader acceptance on a user's device.

This first published ZapFastest release establishes its own update-signing identity. Existing development builds that trust the previous public key need a manual installation of this release before signed updates can be verified. No private signing key is included in the source or downloads.

ZapFastest 0.37.0 integrates memory and performance optimizations, audio stickers, security hardening, and protocol and interface fixes audited from upstream ZapFast pull requests and the Zeus, zapfastie, and zapfast-unvibe forks. Existing linked accounts preserve their sessions, encrypted SQLCipher archives, and settings.

## Performance and memory

- **Thread-local mimalloc heap purging.** Added `purge_thread_heap()` (`libmimalloc-sys` `mi_collect(true)`) so the idle image-decoder thread (after 500 ms idle) and archive maintenance return unused thread-local heap pages to the operating system.
- **Windowed text-selection layout.** Text-selection sweeps in long conversations now lay out only the visible viewport and the rows anchoring the drag ends instead of laying out every message in the chat, reducing RAM spikes and layout latency.
- **Cached and virtualized search results.** Sidebar search results now cache derived view rows and virtualize scrolling while preserving accessibility result announcements.
- **Platform-tuned image cache and sticker residency.** Kept the tighter 96-entry / 48 MiB GPU budget and picker texture eviction on macOS unified memory while restoring 256 entries / 128 MiB and persistent sticker picker textures on Linux and Windows to avoid re-decoding on scroll and tab switches.
- **Linear-time markup parsing.** Rewrote inline WhatsApp markup scanning (`markup.rs`) to run in linear time with a line index, protecting URLs and email addresses from stray formatting markers and preventing quadratic stalls on long unclosed openers.

## New and improved

- **Audio stickers.** Added playback, download, reupload recovery, and animation synchronization for WhatsApp audio stickers both inline in conversations and inside the sticker preview modal, along with startup backfill for previously archived wrapped stickers.
- **Extended polls (V5/V6) and anonymous voting support.** Parsed newer WhatsApp poll message versions, backfilled archived extended polls in batches, respected `hide_voter_names` in poll results, and translated poll creation controls.
- **QR expiration recovery and phone pairing stability.** Exposed expired QR status with a one-click "New code" action on the login screen and waited for socket readiness before starting phone-number pairing.
- **Link previews for YouTube and Instagram.** Added YouTube oEmbed metadata and `i.ytimg.com` thumbnails plus WhatsApp user-agent support for Instagram link previews.
- **Responsive composer, chat list, and dialogs.** Refined composer minimum height, short-window cap, scroll gutter, and bottom fade; stacked reply/media previews cleanly on narrow panes; displayed unread counts on the return-to-bottom button, sync progress percentage during first sync, and member counts for unnamed groups; made mention, forward, and sticker-pack search accent-insensitive; and placed Cancel first with initial focus on destructive confirmation dialogs.

## Fixed

- **Security and privacy hardening.** Updated `url` (`2.5.9`), `form_urlencoded` (`1.2.3`, `RUSTSEC-2026-0592`), and `rustix` (`1.1.6`); enforced strict `whatsapp.net` host validation against SSRF in channel pictures; redacted JIDs and targets from worker logs; cleared raw protobuf blobs, thumbnails, and cached media on message revocation; bounded audio decode duration (1 hour max) and sticker archive decompression (8 MiB entry / 64 MiB total); and persisted suspend-aware lock backoff with a 6-character chat-lock minimum.
- **Protocol and archive correctness.** Tracked `edit_ids` so receipts on edited messages resolve to the target bubble, normalized millisecond ephemeral timestamps, re-armed pending read receipts on chat open, prevented self-overwrite when saving attachments onto their own path, filtered non-chat history sync types from the chat history banner, and allowed removing an account stuck in startup failure.
- **Desktop and Wayland/CachyOS behavior.** Fixed Omarchy `Super+V` clipboard paste grace timing, avoided marking chats read while the window is minimized or hidden, paused inline video playback when handing off to an external player, kept scroll position anchored when loading older history, let Escape leave the archived-chats list, clamped voice waveform widths and audio seek knobs, and fixed a test race in `open_sample_preview` waiting on the stepped viewer texture.

## Verification and limitations

Linux (CachyOS x86_64) verification passed locally before tagging:
- Default features (`cargo test --locked --all-targets`): 2,245 passed (2,229 lib, 13 bin, 3 integration), 0 failed, 16 ignored.
- All features (`cargo test --locked --all-targets --all-features`): 2,247 passed (2,229 lib, 15 bin, 3 integration), 0 failed, 16 ignored.
- Release binary compilation (`cargo build --locked --release`), runtime smoke check (`./target/release/zap-fastest --version`), formatting (`cargo fmt --all --check`), Clippy (`-D warnings` on default and `--all-features`), rustdoc (`-D warnings`), and dependency-source checks all exited 0.

Tests run on Linux only. Windows and macOS binaries and installers are compiled and packaged on GitHub Actions without application test execution. Windows installers are not Authenticode signed, macOS builds are ad-hoc signed without Apple notarization, and releases built without `ZAPFAST_GIPHY_KEY` omit an embedded Giphy key.

ZapFastest 0.31.0-alpha.1 unites upstream ZapFast v0.20 synchronization with ZapFaster power-user workflows and multi-account ergonomics. This baseline release aligns message ordering, archive synchronization, group handling, and media cleanup with the official WhatsApp protocol while preserving the native call engine, offline Whisper voice transcription, and archive-backed gallery.

## What is New in ZapFastest 0.31.0-alpha.1

### Upstream v0.20 Synchronization

- **Server-time message ordering.** Sent messages are positioned using the server timestamp assigned by WhatsApp, preventing outgoing messages from appearing out of order when network replies arrive in close succession (upstream #574).
- **Keep chats archived.** ZapFastest adheres to the phone's "Keep chats archived" preference, keeping archived conversations muted and tucked away when new incoming messages arrive (upstream #572).
- **Cleaner chat list.** Contacts who have never been messaged remain out of the active chat list until an interaction occurs (upstream #573).
- **Phone archive synchronization.** Archiving or unarchiving a conversation locally immediately dispatches the synchronization change to the phone, complete with message range verification, through an asynchronous background queue (upstream #589).
- **Per-chat voice message speed.** Individual chats remember their own playback speed preference without overriding global defaults (upstream #526).
- **Staging file cleanup.** Interrupted or timed-out downloads automatically remove their partial `.part` staging files, preventing orphan disk clutter in media caches (upstream #580).
- **Previous session diagnostics.** When restarting after an unexpected stop, the prior session log is preserved as `zapfast.previous.log` beside the active log (upstream #560).
- **Group creation and invite links.** Create groups directly from New chat and open `whatsapp://chat?code=...` or web group invite links natively (upstream #591).
- **Complete menu translation.** Every contextual message action and submenu label is localized across all supported languages (upstream #552, #565).
- **Desktop polish.** Added Shift+Insert text pasting (upstream #576) and skipped window attention stealing on Hyprland (upstream #562).
- **Security dependency update.** Updated `ctutils` to 0.4.5 to address RUSTSEC-2026-0385.

### Retained ZapFaster Ergonomics

- **Drafts on top.** Chats with unsent text or attachment drafts remain pinned to the top of the chat list for rapid resumption.
- **Archive-backed chat gallery.** Browse media, links, and documents directly from the chat header with instant search.
- **Offline Whisper transcription.** Accurate local CPU voice message transcription powered by Whisper without network telemetry.
- **Multi-account isolation.** Completely independent credentials, local session state, and databases per linked WhatsApp number.
- **Resilient calling.** Compact calling UI layout, ringers for incoming calls, and Sonora local echo cancellation.

## Known Limitations

- Group VoIP repair packets remain in active development; 1:1 voice and video calls continue using our stable native pipelines.
- Multi-account switching requires restarting or toggling via Ctrl+Shift+A when multiple linked accounts are configured.
